# Sales Dashboard - Next.js 15 + TypeScript + Tailwind CSS

## Project Overview

This project is a simple **Sales Dashboard** built with Next.js 15, TypeScript, and Tailwind CSS. It follows the **atomic design principle**, breaking components into **atoms, molecules, and organisms**.

The dashboard displays **mock sales data** for 2022, 2023, and 2024 using a **bar chart** from Recharts.

## Features

- File-system based routing with Next.js
- Atomic design structure
- Responsive **bar chart** for sales
- Mock sales data

## Enhancements (Future)

- Custom filter input for setting sales thresholds
- Fetch real data from an API
- Support for multiple chart types (bar, line, pie)

## Technologies

- Next.js 15
- TypeScript
- Tailwind CSS
- Recharts
